# LLMs locais e arquitetura de computadores

Apresentação estática da semana 1. Astro, Reveal.js e os dados do experimento em `src/data`.

## Uso

```bash
npm install
npm run dev
```

```bash
npm run validate
npm run build
npm run preview
```

`npm run build:pages` gera os caminhos do GitHub Pages.

## Apresentar

Setas ou o clique nas laterais mudam de slide. F tela cheia. Esc visão geral. Home volta ao início. S abre o modo apresentador.

A página publicada fica em `https://talyslan1.github.io/llm-locais-arquitetura-de-computadores/`. O workflow `.github/workflows/pages.yml` publica o branch `main`.

Depois do carregamento, imagens, fonte e gráficos vêm do próprio site.

## Imagens

Créditos, licenças e links estão em `src/data/images.ts`. Fotos sem o modelo exato aparecem como ilustrativas.
